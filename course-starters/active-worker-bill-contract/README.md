# 员工状态过滤：自生成契约测试样例

这个项目根据公开的 A1–A6 验收场景独立编写。人员编号、状态响应和账单存储都是合成数据或内存替身；这里没有业务后端源码、内部接口、真实账号或数据库连接。

`src/bill_contract/sample_adapter.py` 是供练习和测试运行的**示例实现**。测试通过只说明这个示例符合本项目的公开契约，不能证明真实后端或 SIT 已通过。要验证真实系统，需在有权限的私有环境中另建适配层，接入实际接口和数据库读回，并单独保存证据。

## 运行

需要 Python 3.9+ 和 pytest。在本目录执行：

```sh
python3 -m pytest -q
```

测试对应：A1 全部在职；A2 混合状态；A3 缺失或未返回；A4 查询失败；A5 超过 500 人分批；A6 已有账单不重复写入。

## 学习用法

- API 自动化：替换 `FakeStatusGateway` 的响应，观察失败批次与空结果的区别。
- 质量工程：修改示例实现并用 A1–A6 判断是否破坏过滤、查重或无写入约束。
- 接入真实系统时，只复用测试意图和合成数据结构；实际请求、认证、数据准备和清理由私有适配层负责。
