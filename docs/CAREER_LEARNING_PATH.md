# 服务端测试开发与质量工程学习路线

2026-11-06：按招聘岗位分析与测试开发能力模型调整课程。建议主线为服务端测试开发、质量工程，AI 测试与评测作为特色能力。个人熟练程度仍需通过独立任务确认。

## 课程顺序

1. Python 框架基础 → 独立编码与调试。
2. 计算机与服务端基础。
3. API 自动化 → 质量工程与保障。
4. 故障定位与工程交付 → 性能测试。
5. Python Agent 快速通道 → AI 测试与评测。

UI 自动化与 AI 开发扩展保留为专项选修。前置课程是建议学习依赖，不锁住已有学习者。既有课程 ID、前十关 ID 和本机草稿键保持可用，案例继续映射原有关卡。

## 可运行练习

网页提供 quality-engineering-lab.zip，源码在 course-starters/quality-engineering-lab。五项任务覆盖失败归组、库存幂等、失败分类、发布门禁、分类指标。默认运行学员 src，TODO 初始应失败；--reference 只验证参考实现。网页草稿和本地代码不会自动同步，测试日志还没有接入网页通关状态。

生成下载包：python3 scripts/package-quality-lab.py。仅打包明确扩展名的源码、测试、说明和 CI 样例，不打包缓存、凭据或本地数据。

本地运行参考实现只能证明样例契约，不代表真实后端、数据库并发、生产幂等或远程 CI 已通过。涉及 SQL、缓存、消息、容器和灰度的任务需在隔离环境执行并另存证据。
